# 聊天屏蔽词目录

此目录由服务端聊天安全检查直接读取。当前分为：

- `violence.txt`：血腥、暴力、自残等内容。
- `sexual.txt`：色情、裸聊、性交易等不良内容。
- `fraud.txt`：银行卡、转账、验证码、刷单、投资诈骗等资金风险内容。

维护方式：

1. 每行填写一个需要拦截的词或短语。
2. 空行会被忽略，以 `#` 开头的行是说明注释。
3. 保存文件后，新词会在下一条消息发送时自动生效，不需要重启服务器。
4. 可以新增其他 `.txt` 文件作为新分类，例如 `harassment.txt`。
5. 系统会忽略大小写、常见空格和标点，例如“转 账”和“转-账”同样会命中“转账”。

维护建议：优先使用明确的风险短语，不要加入“钱”“血”“卡”等过短的单字，以免误伤正常聊天。敏感词只能作为基础防线，正式上线时建议再接入人工举报、管理员审核和专业内容安全服务。
